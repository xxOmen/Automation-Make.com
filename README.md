# Automation-Make.com 🚀
A Make.com (Integromat) automation that fetches trending topics from Google Trends and IGN RSS feeds, generates SEO-optimized Blogger articles using OpenAI GPT-5-nano, and automatically posts them to Blogger or via email.

## ⚙️ Features
- Pulls trending data from Google Trends & IGN.
- Uses GPT-5-nano for content generation.
- Produces clean, SEO-ready HTML articles.
- Publishes automatically to Blogger (or email-to-post).
- Easy to extend for other CMS or websites.

## 🧠 Tech Stack
- Make.com (HTTP, RSS, Router, Blogger modules)
- OpenAI GPT-5-nano API
- Google Blogger API / Gmail integration

## 🚀 How to Use
1. Import the provided blueprint JSON into Make.com.
2. Add your OpenAI and Google connections.
3. Configure your Blogger ID or email posting address.
4. Run the scenario manually or schedule it daily.
